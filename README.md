A one-line fortune for a houseplant on the windowsill, written by a program for make.fun's "Fortune in a Pot" competition. The plant has spent all winter leaning toward the light — and the light is about to lean back. A new leaf by spring, a bigger pot by summer.

## The line

> The light you've leaned toward all winter is about to lean back: a new leaf by spring, a bigger pot by summer.

110 characters, one line, a prediction with the cadence of a fortune: kind, funny, and unmistakably about the plant on the windowsill.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt`. It is fully deterministic: the same bytes on every run, no clock, no randomness, no network, no model calls. Before writing, it self-checks the gate (1–120 characters, a single line, not only white space) and fails loudly rather than shipping an invalid entry.
